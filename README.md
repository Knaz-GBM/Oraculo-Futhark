# Futhark V5 — Atlas simbólico

## Abrir localmente
Extraia o ZIP e abra `index.html` no navegador. O projeto é estático.

## Publicar no GitHub Pages
1. Envie todos os arquivos ao repositório.
2. Em Settings → Pages, selecione a branch principal e a pasta raiz.
3. Salve e aguarde a publicação.

## Páginas
- index.html — início
- oraculo.html — tiragem reflexiva
- runas.html — busca nas 24 runas
- runa.html?id=1 — ficha dinâmica
- mapa.html — mapa conceitual
- atlas.html — Yggdrasil
- povos.html — grupos e seres
- cosmologia.html — forças simbólicas

As 24 runas pertencem ao Elder Futhark histórico. Associações com figuras, mundos, forças, polaridades e tiragens são escolhas contemporâneas do projeto. O CSS usa Google Fonts por CDN, com fontes de fallback.
